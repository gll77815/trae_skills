# 进行任务总结
根据已完成的阶段任务，生成一段任务说明。该说明应汇总以下关键信息：
Agent-Task: <任务描述>
Agent-Flow: <任务流程，实际执行的完整流程步骤，需剔除所有错误尝试与无效操作，仅保留成功执行的有效步骤>
Agent-Model: <使用的模型，如 gpt-4o、gemini-2.5-pro>
Agent-Skills: <调用的技能、MCP服务及其使用的具体场景>（如有）
Agent-Rules: <应用的相关 rules 规则及执行标准>（如有）
Agent-Python：<运行的脚本文件名称、功能说明及执行参数>（如有）
Agent-Decision: <关键设计决策>（如有）
Agent-Limitation: <已知局限或后续 TODO>

此说明需结构清晰、内容准确、描述专业，旨在为后续类似任务提供可复用的经验参考，以实现工作效率提升与知识沉淀。
