# Agent Alias - 智能体命名与编排技能

## 这是什么？

Agent Alias 是一个智能体管理技能，帮助你用**角色化**的方式创建和管理 AI 智能体。

就像在团队中，你通过同事的姓名就知道他的职责和能力一样，Agent Alias 让你可以给 AI 技能起名字、设岗位、配能力，然后通过 `/姓名` 直接唤醒。

## 快速上手

### 1. 创建一个智能体

```
创建智能体小李，是产品经理，擅长PRD撰写
```

系统会引导你补充能力标签、技能包、工作边界等信息，然后自动生成一个可斜杠唤醒的子技能。

### 2. 唤醒智能体

```
/小李 帮我写一份电商APP的PRD
```

### 3. 管理智能体

```
查询智能体        → 查看所有已创建的智能体
更新智能体小李    → 修改智能体信息
删除智能体小李    → 删除智能体
```

## 核心特性

| 特性 | 说明 |
|------|------|
| 角色化命名 | 用同事姓名或角色名命名智能体，直观易记 |
| 斜杠唤醒 | 创建后即可用 `/姓名` 直接唤醒 |
| 能力编排 | 为智能体配置技能包和调用技能 |
| 边界约束 | 定义智能体能做什么、不能做什么 |
| 工作组 | 组建多智能体协作团队 |
| 多维检索 | 按姓名/岗位/标签/能力检索智能体 |

## 存储结构

```
.trae/skills/
├── agent-alias/           # 本技能（管理中枢）
│   ├── SKILL.md
│   └── workflows/         # 管理流程文档
├── {智能体名}/            # 由本技能创建的智能体
│   └── SKILL.md
└── workgroups/            # 工作组
    └── {工作组名}/
        └── SKILL.md
```

## 依赖

本技能无外部依赖。创建的智能体可以引用其他已安装的技能（如 `bmad-agent-pm`、`slides` 等）。
