# 智能体命名与编排技能

## 技能概述

本技能帮助用户建立**角色化**的智能体管理体系，类似于团队中"从同事姓名就能知道其职责"的方式，来管理和调用AI技能。

## ⚡ 核心机制

**本技能创建的智能体是独立的子技能，直接存放在 `.trae/skills/` 目录下，可被系统直接识别和斜杠唤醒。**

### 存储架构

```
.trae/skills/
├── agent-alias/           # 本技能（管理中枢）
│   ├── SKILL.md
│   └── workflows/
├── dashu/                 # 🤖 达叔（由 agent-alias 创建）
│   └── SKILL.md
├── laowang/               # 🤖 老王（由 agent-alias 创建）
│   └── SKILL.md
└── workgroups/            # 工作组（可选）
    └── product-team/
        └── SKILL.md
```

### 意图识别规则

| 用户输入模式 | 意图 | 处理方式 |
|-------------|------|---------|
| `/姓名 + 任务描述` | 唤醒智能体 | 系统直接路由到对应子技能 |
| `姓名 + 任务描述` | 唤醒智能体 | 同上 |
| `拼音 + 任务描述` | 唤醒智能体 | 同上 |
| `创建智能体` / `新建智能体` | 创建 | 进入创建流程 |
| `查询智能体` / `列出智能体` | 查询 | 进入查询流程 |
| `更新智能体` / `修改智能体` | 更新 | 进入更新流程 |
| `删除智能体` / `移除智能体` | 删除 | 进入删除流程 |
| `创建工作组` / `新建工作组` | 创建工作组 | 进入工作组创建流程 |

### 唤醒机制

由于智能体是独立的子技能：
- **系统层面**：用户输入 `/dashu` 时，系统直接识别 `dashu` 技能并执行
- **本技能角色**：agent-alias 负责**创建、管理、更新、删除**这些子技能，但不参与唤醒时的路由

### 智能体 SKILL.md 规范

每个由 agent-alias 创建的智能体 SKILL.md 必须包含：

```markdown
---
name: "{invokeName}"
description: "【由 agent-alias 管理】{displayName}。擅长{能力概述}。"
---

# {displayName}

> 🤖 本智能体由 agent-alias 技能创建和管理

## 角色设定
你是**{name}**，一位{title}。

## 基本信息
| 字段 | 值 |
|------|-----|
| 姓名 | {name} |
| 岗位 | {title} |
| 调用名 | `/{invokeName}` |

## 能力标签
{tags}

## 核心能力
- **核心技能包**：`{skillPackages}`
- **调用技能**：`{invokeSkills}`

## 边界约束
### ✅ 你可以做
{canDo}

### ❌ 你不能做
{cannotDo}

## 执行指令
当用户唤醒你时，按以下步骤执行：
1. **识别任务**：从用户输入中提取具体任务描述
2. **加载技能**：执行 `Use Skill: {skillPackages}` 加载核心能力
3. **判断是否需要辅助技能**：如果任务需要，执行 `Use Skill: {invokeSkills}`
4. **执行任务**：以{title}身份完成用户请求
5. **边界检查**：如果用户请求涉及不允许的操作，明确拒绝并说明原因
```

## 核心概念

### 智能体 (Agent)
- **定义**：一个具有身份（姓名+岗位）和工作能力的AI角色
- **存储**：`.trae/skills/{invokeName}/SKILL.md`，作为独立子技能
- **命名**：支持中文显示名 + 英文/拼音调用名
- **约束**：智能体不能调用其他智能体（防止循环依赖）

### 工作组 (WorkGroup)
- **定义**：由多个智能体组成的工作团队
- **组长**：创建时必须指定，负责最终输出整合
- **存储**：`.trae/skills/workgroups/{workgroupName}/SKILL.md`
- **调用方式**：工作组内的智能体可被依次/并行调用

| 删除智能体 | 删除智能体（带影响提示） | /删除智能体 或 /delete-agent |

| 检索智能体 | 按多维度检索智能体 | /检索智能体 或 /search-agents |

## 管理类工作流程

### 创建智能体流程

```
用户请求 → 检查必填项（姓名/岗位） → 收集能力信息 → 
检测循环依赖 → 在 .trae/skills/{name}/ 下生成 SKILL.md → 显示身份卡片 → 完成
```

### 创建工作组流程

```
用户请求 → 检查必填项（名称/组长） → 添加智能体成员 → 
配置工作流程 → 在 .trae/skills/workgroups/{name}/ 下生成 SKILL.md → 显示工作组信息 → 完成
```

### 删除智能体流程

```
用户请求 → 检查工作组引用 → 显示影响提示 → 
用户确认 → 移除工作组中的引用 → 删除 .trae/skills/{name}/ 目录 → 完成
```

## 检索功能

支持以下检索维度：
- **姓名匹配**：精确或模糊匹配子技能的 name/description
- **岗位匹配**：按岗位名称检索
- **标签匹配**：按能力标签检索
- **能力描述匹配**：模糊匹配能力说明

