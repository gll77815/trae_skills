# 查询与检索子技能

## 触发条件

当用户请求查询或检索智能体时触发：
- 用户说"查询智能体"、"查看智能体"、"列出所有智能体"
- 用户说"搜索智能体"、"找找能做XX的"
- 用户说"/list-agents" 或 "/search-agents"

## 查询模式

### 模式1：列出全部

扫描 `.trae/skills/` 目录，筛选所有包含 `【由 agent-alias 管理】` 标记的 SKILL.md 文件：

```
📋 智能体列表（共 N 个）

🤖 智能体：
├─ [1] 小李 - 产品经理 - #PRD #需求分析
├─ [2] 老王 - 高级产品经理 - #PRD #架构设计

👥 工作组：
├─ [3] 产品团队 - 组长：小李 - 成员：2人
```

### 模式2：查看单个详情

读取对应 SKILL.md，渲染身份卡片：

```
┌─────────────────────────────────────────────────────────────┐
│  🤖 智能体：小李                                              │
├─────────────────────────────────────────────────────────────┤
│  岗位：产品经理  │  状态：✅ 启用                             │
├─────────────────────────────────────────────────────────────┤
│  能力标签：#PRD #需求分析                                    │
├─────────────────────────────────────────────────────────────┤
│  工作能力：                                                   │
│  ├─ 📦 技能包：bmad-agent-pm                                │
│  ├─ 🔧 调用skills：bmad-brainstorming                      │
│  └─ 🚫 边界：不涉及技术实现细节                               │
├─────────────────────────────────────────────────────────────┤
│  调用方式：/xiaoli                                           │
│  📁 目录：.trae/skills/xiaoli/SKILL.md                      │
└─────────────────────────────────────────────────────────────┘
```

### 模式3：按条件检索

支持多种检索维度：

#### 3.1 按姓名/调用名检索
匹配 SKILL.md 的 `name` 字段和正文中的"姓名"字段。

#### 3.2 按岗位检索
匹配正文中的"岗位"字段。

#### 3.3 按标签检索
匹配正文中的"能力标签"部分。

#### 3.4 按能力描述检索（模糊匹配）
匹配 SKILL.md 的 `description` 字段和正文内容。

#### 3.5 组合检索
支持同时按多个维度筛选。

## 检索算法

### 匹配规则

| 匹配类型 | 示例 | 匹配内容 |
|----------|------|----------|
| 调用名精确匹配 | "xiaoli" | SKILL.md `name: "xiaoli"` |
| 姓名包含 | "小李" | 正文中的"姓名"字段 |
| 岗位包含 | "产品" | 正文中的"岗位"字段 |
| 标签包含 | "PRD" | "能力标签"部分 |
| 描述包含 | "调研" | `description` 字段或正文 |

### 权重计算

- 调用名精确匹配：100分
- 岗位匹配：80分
- 标签匹配：60分
- 能力描述匹配：40分
- 模糊匹配：20分

## 交互流程

### 查询全部流程
```
用户：列出所有智能体
    ↓
系统：扫描 .trae/skills/ 目录
    ↓
系统：筛选包含"【由 agent-alias 管理】"的 SKILL.md
    ↓
系统：解析并显示列表
```

### 检索流程
```
用户：找找能做PRD的
    ↓
系统：解析检索条件
    ↓
系统：扫描所有 agent-alias 管理的 SKILL.md
    ↓
系统：计算匹配度并排序
    ↓
系统：显示结果
```

## 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 无智能体 | 提示用户尚未创建任何智能体，引导创建 |
| 无匹配结果 | 显示"未找到匹配结果"，提供建议 |
| 文件损坏 | 跳过并警告，列出其他可用智能体 |
| 关键字歧义 | 显示所有可能匹配供用户选择 |

## 快捷操作

查询结果支持快捷操作：
```
🤖 小李 - 产品经理
├─ [1] 查看详情
├─ [2] 更新信息
├─ [3] 删除智能体
└─ [4] 复制调用命令
```
