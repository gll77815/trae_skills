# 更新与删除子技能

## 触发条件

当用户请求更新或删除智能体/工作组时触发：
- 用户说"更新智能体"、"修改智能体"、"给XX添加技能"
- 用户说"删除智能体"、"移除智能体"
- 用户说"/update-agent" 或 "/delete-agent"

---

# 更新智能体

## 执行流程

### 第一步：选择要更新的智能体

扫描 `.trae/skills/` 下所有由 agent-alias 管理的 SKILL.md，列出供选择：

```
📝 选择要更新的智能体：

[1] 小李 - 产品经理
[2] 老王 - 高级产品经理

请选择编号（输入0取消）：
```

### 第二步：显示当前信息

读取 SKILL.md 内容，展示可更新的字段：

```
📋 当前信息：

[1] 姓名：小李
[2] 岗位：产品经理
[3] 能力标签：#PRD #需求分析
[4] 技能包：bmad-agent-pm
[5] 调用skills：bmad-brainstorming
[6] 工作边界
[7] 示例用法

请选择要修改的字段编号（多选用逗号分隔）：
```

### 第三步：逐项修改

对于每个选中的字段，提示用户输入新值。

### 第四步：确认更新

```
📋 更新确认

修改内容：
├─ 岗位：产品经理 → 产品总监
└─ 能力标签：新增 #产品规划

[1] 确认更新
[2] 继续修改
[3] 取消
```

### 第五步：执行更新

用户确认后，直接修改 `.trae/skills/{invokeName}/SKILL.md` 文件中对应的内容。

---

# 删除智能体

## 执行流程

### 第一步：选择要删除的智能体

```
⚠️ 删除确认

请选择要删除的智能体：

[1] 小李 - 产品经理
[2] 老王 - 高级产品经理

⚠️ 警告：删除后不可恢复！
```

### 第二步：检查工作组引用

扫描 `.trae/skills/workgroups/` 下所有工作组 SKILL.md，检查是否有工作组引用了该智能体。

**场景A：有引用**
```
⚠️ 检测到引用

智能体"小李"被以下工作组引用：

[1] 产品团队
   └─ 角色：产品规划（组长）
   └─ 影响：移除此成员后需指定新组长

📝 请选择删除方式：
[1] 仅删除智能体（从工作组中自动移除）
[2] 先补充替代智能体，再删除
[3] 先移除受影响的工作组，再删除
[4] 取消删除
```

**场景B：无引用**
```
✅ 无引用检测

智能体"小李"未被任何工作组引用，可以安全删除。

⚠️ 警告：删除后不可恢复！

[1] 确认删除
[2] 取消
```

### 第三步：执行删除

用户确认后：
1. 如有工作组引用，从工作组 SKILL.md 中移除该成员
2. 删除 `.trae/skills/{invokeName}/` 整个目录

---

# 更新工作组

## 执行流程

### 第一步：选择要更新的工作组

扫描 `.trae/skills/workgroups/` 下所有工作组 SKILL.md：

```
📝 选择要更新的工作组：

[1] 产品团队 - 成员：2人
[2] 开发评审组 - 成员：3人

请选择编号：
```

### 第二步：显示当前信息并修改

展示可更新字段（名称、组长、成员、工作流程、输出物），用户选择后逐项修改。

### 第三步：确认并保存

修改 `.trae/skills/workgroups/{name}/SKILL.md` 中对应内容。

---

# 删除工作组

## 执行流程

### 第一步：选择要删除的工作组

```
⚠️ 删除确认

请选择要删除的工作组：

[1] 产品团队 - 成员：2人

⚠️ 警告：删除后不可恢复！
```

### 第二步：确认并删除

删除工作组不会影响成员智能体（它们是独立的子技能）。

删除 `.trae/skills/workgroups/{name}/` 整个目录。

---

# 通用边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 目标不存在 | 提示用户检查名称后重试 |
| 无修改内容 | 提示无需更新 |
| 字段为空 | 提示用户补充或跳过 |
| 文件保存失败 | 保留原文件，提示错误 |

# 示例对话

### 更新示例
```
用户：给小李添加 slides 技能

系统：
📝 找到智能体"小李"

当前技能包：bmad-agent-pm
当前调用skills：bmad-brainstorming

确认添加 slides 技能？[y/n]：y

✅ 更新成功！
├─ 调用skills：bmad-brainstorming, slides（新增）
```

### 删除示例
```
用户：删除智能体小李

系统：
⚠️ 检测到引用

智能体"小李"被以下工作组引用：
产品团队 - 角色：产品规划（组长）

📝 请选择删除方式：
[1] 仅删除智能体（从工作组中自动移除）
[2] 取消删除

用户：1

✅ 删除成功
智能体"小李"已删除。
已从"产品团队"中移除引用。
```
