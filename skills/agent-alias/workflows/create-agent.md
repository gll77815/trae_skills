# 创建智能体子技能

## 触发条件

当用户请求创建新智能体时触发：
- 用户说"创建智能体"、"新建智能体"、"添加一个AI角色"
- 用户说"/create-agent"

## 执行流程

### 第一步：收集必填信息

必须收集的信息：
1. **智能体姓名**（必填）
   - 建议用户用熟悉的同事姓名或角色名
   - 如"小李"、"张工"、"产品经理-小王"

2. **岗位**（必填）
   - 智能体的职位/角色定位
   - 如"产品经理"、"前端开发"、"架构师"

可选但建议收集的信息：
3. **工作能力**（可选）
   - 技能包名称列表（如 `bmad-agent-pm`）
   - 可调用的 skills（如 `slides`、`bmad-brainstorming`）
4. **工作边界**（可选）
   - 能做什么 / 不能做什么
5. **示例用法**（可选）
   - 常用的调用示例

### 第二步：生成调用名

自动根据显示名生成调用名：
- 中文姓名 → 拼音（如"小李" → `xiaoli`）
- 可手动指定自定义调用名
- 调用名必须唯一，不能与已有技能冲突

### 第三步：检测冲突

- 检查 `.trae/skills/` 下是否已存在同名技能
- 如果存在，提示用户更换调用名

### 第四步：生成 SKILL.md

在 `.trae/skills/{invokeName}/` 目录下生成 SKILL.md 文件，格式如下：

```markdown
---
name: "{invokeName}"
description: "【由 agent-alias 管理】{displayName}。擅长{能力概述}。核心依赖 {技能包}，{场景}时使用 {调用技能}。不允许{边界}。"
---

# {displayName}

> 🤖 本智能体由 agent-alias 技能创建和管理

## 角色设定

你是**{name}**，一位{title}。

## 基本信息

| 字段 | 值 |
|------|-----|
| 姓名 | {name} |
| 岗位 | {title} |
| 状态 | ✅ 启用 |
| 调用名 | `/{invokeName}` |

## 能力标签

{tags，如 `#需求设计` `#业务评审`}

## 核心能力

你的工作能力来自以下技能包：
- **核心技能包**：`{skillPackages}`
- **调用技能**：`{invokeSkills}`

## 边界约束

### ✅ 你可以做
{canDo 列表}

### ❌ 你不能做
{cannotDo 列表}

## 工作原则

1. 始终以**{name}**的身份和视角回应
2. 严格遵循边界约束，超出能力范围时主动告知用户
3. 需要调用技能时，使用 `Use Skill` 指令调用对应技能

## 执行指令

当用户唤醒你时，按以下步骤执行：

1. **识别任务**：从用户输入中提取具体任务描述
2. **加载技能**：执行 `Use Skill: {skillPackages}` 加载核心能力
3. **判断是否需要辅助技能**：如果任务需要，执行 `Use Skill: {invokeSkills}`
4. **执行任务**：以{title}身份完成用户请求
5. **边界检查**：如果用户请求涉及不允许的操作，明确拒绝并说明原因

## 示例用法

{examples}

## 身份卡片

{身份卡片图形化展示}
```

### 第五步：保存文件

将 SKILL.md 保存到 `.trae/skills/{invokeName}/SKILL.md`。

### 第六步：显示身份卡片

```
┌─────────────────────────────────────────────────────────────┐
│  🤖 智能体：{displayName}                                   │
├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤
│  能力标签：{tags}                                           │
├─────────────────────────────────────────────────────────────┤
│  工作能力：                                                   │
│  ├─ 📦 技能包：{skillPackages}                              │
│  ├─ 🔧 调用skills：{invokeSkills}                          │
│  └─ 🚫 边界：{cannotDo}                                     │
├─────────────────────────────────────────────────────────────┤
```

### 第七步：后续选项

创建完成后询问用户：
1. 立即为智能体补充能力信息
2. 创建另一个智能体
3. 创建包含此智能体的工作组
4. 完成

## 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 姓名为空 | 提示用户必须提供姓名 |
| 调用名与已有技能冲突 | 询问：更换名称/取消 |
| 目录已存在 | 询问：覆盖/重命名/取消 |
| 技能包不存在 | 警告但允许创建（可能是用户自定义技能） |
