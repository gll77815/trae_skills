# 创建工作组子技能

## 触发条件

当用户请求创建工作组时触发：
- 用户说"创建工作组"、"新建工作组"、"创建团队"
- 用户说"/create-workgroup"

## 执行流程

### 第一步：收集必填信息

必须收集的信息：
1. **工作组名称**（必填）
   - 如"产品团队"、"开发评审组"

2. **组长**（必填）
   - 从现有智能体（`.trae/skills/` 下由 agent-alias 创建的子技能）中选择
   - 组长负责最终输出整合

3. **成员列表**（必填，至少1个）
   - 从现有智能体中选择，可多选
   - 每个成员需要说明职责

可选信息：
4. **工作流程**（可选）：串行/并行/协商
5. **最终输出物**（可选）：工作组的交付成果

### 第二步：验证成员存在

扫描 `.trae/skills/` 目录，检查所有成员的 SKILL.md 是否存在：
- 全部存在 → 继续
- 部分不存在 → 列出缺失的，询问是否移除或先创建

### 第三步：配置成员职责

为每个成员配置角色和职责描述。

### 第四步：生成调用名

自动生成调用名，确保不与已有技能冲突。

### 第五步：生成 SKILL.md

在 `.trae/skills/workgroups/{workgroupName}/` 目录下生成 SKILL.md：

```markdown
---
name: "{invokeName}"
description: "【由 agent-alias 管理·工作组】{displayName}。组长：{leaderName}，成员：{memberCount}人。{output}。"
---

# {displayName}

> 🤖 本工作组由 agent-alias 技能创建和管理

## 工作组信息

| 字段 | 值 |
|------|-----|
| 名称 | {name} |
| 组长 | {leaderName} |
| 成员数 | {memberCount}人 |
| 工作流程 | {workFlow} |
| 最终输出 | {output} |

## 成员列表

{每个成员的详细信息：姓名、岗位、角色、职责}

## 执行指令

当用户唤醒工作组时：
1. 识别任务并分配给各成员智能体
2. 按工作流程执行（串行/并行/协商）
3. 组长负责最终输出整合
4. 如成员输出矛盾，询问用户决策
```

### 第六步：保存文件

保存到 `.trae/skills/workgroups/{workgroupName}/SKILL.md`。

### 第七步：显示工作组信息

```
┌─────────────────────────────────────────────────────────────┐
│  👥 工作组：{displayName}                                    │
├─────────────────────────────────────────────────────────────┤
│  组长：🤖 {leaderName}                                      │
├─────────────────────────────────────────────────────────────┤
│  成员：                                                       │
│  ├─ 🤖 {member1} - {role1}                                  │
│  └─ 🤖 {member2} - {role2}                                  │
├─────────────────────────────────────────────────────────────┤
│  工作流程：{workFlow}  │  输出：{output}                     │
├─────────────────────────────────────────────────────────────┤
│  调用方式：/{invokeName}                                     │
│  📁 目录：.trae/skills/workgroups/{name}/SKILL.md          │
└─────────────────────────────────────────────────────────────┘
```

## 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 组长不存在 | 提示先创建或重新选择 |
| 成员列表为空 | 必须至少添加一个成员 |
| 组长不在成员列表 | 自动将组长添加到成员列表 |
| 工作组名冲突 | 询问：覆盖/重命名/取消 |
