# your-slides 系列

一组按"演讲场景"划分的幻灯片改造技能。每个子技能聚焦一种叙事范式，互不混用。

## 子技能一览

| 子技能 | 场景 | 状态 |
|---|---|---|
| **launch-slides** | 产品发布会叙事 — 苹果式克制、华为/小米式气势、特斯拉式数据墙、故事弧线 | ✅ 完整可用 |
| **work-report-slides** | 工作汇报 — 周报式、月度复盘、项目里程碑、BLUF 向上汇报 | ✅ 完整可用 |
| **academic-slides** | 学术交流 — 经典章节式、答辩 Q&A、Poster、Figure 主导 | 🟡 占位（下一个补全） |

## 为什么分开

发布会、学术、工作汇报三种语境的底层假设完全不同：

- **发布会**：信息密度低、留白多、靠金句和递进打感染力，**删信息换冲击力**
- **学术**：信息密度高、引用充分、图表是主角，**信息保真度高于美感**
- **工作汇报**：结论先行、数据指标外露、闭环行动项，**让看的人能立刻决策**

把它们做成不同技能，是为了让每种触发场景都能拿到匹配的反模式清单和布局模板，而不是一套通用的"PPT 美化"提示词。

## 共同约定（所有子技能都遵守）

1. **不破坏当前页**：每次改之前先问"复制再改 vs 直接改"，默认复制
2. **设计先行**：先输出文字版设计方案让用户确认，再动手画
3. **输出格式可选**：用户能选 HTML / PPTX / PNG（具体支持范围见每个子技能的 `formats/`）

各子技能内部细节见对应目录的 `SKILL.md`。
