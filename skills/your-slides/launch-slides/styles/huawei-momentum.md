# 风格 B — 华为/小米式·气势递进

顶部主张 + 中部 Before/After 对比 + 底部数字证据。**核心审美：层层加码，越往下越震撼**。

## 布局图（基准尺寸 960×540）

```
+--------------------------------------------------+
|         [顶部大主张, 40pt, 居中]                   |  ← y=40
|                                                  |
|     传统做法              我们的做法               |  ← y=140, Before/After 标
|   ┌────────────┐       ┌────────────┐           |
|   │            │       │            │           |  ← y=180, 两个对比块
|   │ 灰暗示意    │       │ 高亮示意    │           |     宽 320, 高 180
|   │            │       │            │           |
|   └────────────┘       └────────────┘           |
|                                                  |
|  59          14天        ¥350K        100%       |  ← y=400, 数字 56pt
|  健康分      延期         成本         闭环        |  ← y=470, 单位 14pt
+--------------------------------------------------+
```

## 配色

| 元素 | 颜色 | 说明 |
|---|---|---|
| 背景 | `#0A0E1A` | 深蓝黑 |
| 顶部主张 | `#FFFFFF` | 纯白 |
| Before 块 | `#2A3340` | 灰暗背景 |
| Before 文字 | `#6B7F94` | 灰文字（"丧气"感） |
| After 块 | `#E0762D` 50% 不透明 | accent 橙半透明 |
| After 文字 | `#FFFFFF` | 高亮白 |
| 数字 | `#E0762D` | accent 橙 56pt |
| 单位 | `#9CB3CC` | 浅灰蓝 14pt |

## 字号锚点

| 元素 | 字号 |
|---|---|
| 顶部主张 | 40pt |
| Before/After 标签 | 18pt |
| 对比块内文字 | 16pt |
| 数字 | 56pt |
| 单位 | 14pt |

## Before/After 对比块尺寸

- 宽度 **320px**，高度 **180px**，圆角 8px
- 居中分布：左块 x=128，右块 x=512
- 两块之间留 32px 空隙

## 何时用这个风格

- 内容包含"传统做法 vs 新做法"对比
- 用户想强调"我们打败了过去"
- 有清晰的量化数字（≥3 个）支撑底部证据墙

## 实现要点

- 对比块的"灰暗"感要做出来：Before 用低饱和、低对比；After 用高饱和、半透明 accent
- 数字要孤立呈现，**不要加千分位逗号**（"350,000" 的视觉冲击力远小于 "¥350K"）
- 数字与单位组合用两个 textbox 上下排，不要写成一行
- 顶部主张如果想更有气势，可以加副标题 24pt 在 y=92
