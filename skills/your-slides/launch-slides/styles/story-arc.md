# 风格 D — 故事弧线式

从左到右：痛点 → 转折 → 解法 → 价值，像时间轴。**核心审美：让眼睛随着叙事线走完一遍**。

## 布局图（基准尺寸 960×540）

```
+--------------------------------------------------+
|                                                  |
|   痛点  ───→  转折  ───→  解法  ───→  价值        |  ← y=80, 四阶段标
|  (icon)      (icon)      (icon)     (icon)       |  ← y=120, 32px icon
|                                                  |
|  方案归档    重新定义     穿透工序    工期-14天    |  ← y=220, 16pt 加粗
|  无人执行    技术管理     自动拦截    成本-¥350K   |  ← y=250, 14pt 注解
|                                                  |
|  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━           |  ← y=320, 时间线 2pt
|   ●           ●           ●           ●          |  ← 四节点圆点
|                                                  |
|      [底部一行总结金句, 20pt, 居中]                |  ← y=400
|                                                  |
+--------------------------------------------------+
```

| 转折 | `#E0762D` | 暖橙，"觉醒" |
| 解法 | `#59C2ED` | 亮蓝，"清晰" |

| 阶段 | 中心 x 坐标 | 列宽 |
|---|---|---|
| 痛点 | 120 | 240 |

| 解法 | 600 | 240 |

## 何时用这个风格

- 内容本身有清晰的"演变叙事"（before → after，但有过程感）
- 想强调"我们走过了哪些路"
- 需要把"问题—觉察—解决—收益"四阶段都说出来，缺一不可

## 实现要点

- **icon 必须不一样**：痛点用警示/❌、转折用💡、解法用🛠️、价值用✓/✨。如果实现时没法用 emoji，用形状代替（圆/三角/方块/星）
- 阶段之间的箭头 `───→` 用细线或浅灰，不要喧宾夺主
- 时间线节点的圆点颜色对应阶段渐进色（灰 → 橙 → 蓝 → 白），让叙事流动感更强
- 底部总结金句一定要有，否则整页变成"四段并列描述"，失去弧线感
- 不要给阶段加底色块——否则又变回"四张卡片"，就不叙事了
