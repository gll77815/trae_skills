# 风格 C — 特斯拉式·一句话 + 数据墙

一句颠覆性宣言占中央，周围是关键数字。**核心审美：宣言一锤定音 + 数据当场印证**。

## 布局图（基准尺寸 960×540）

```
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|     [中央颠覆性宣言, 60pt, 居中]                   |  ← y=180-280
|        [一行小注解, 16pt, 居中]                    |  ← y=290
|                                                  |
|                                                  |
|                                                  |
|   59     |   14    |  ¥350K   |   100%           |  ← y=430, 数字 48pt
|  健康分   |  延期   |   成本    |   闭环          |  ← y=485, 单位 12pt
+--------------------------------------------------+
```

## 配色

| 元素 | 颜色 | 说明 |
|---|---|---|
| 背景 | `#0A0E1A` 或 `#000000` | 深蓝黑 / 纯黑 |
| 宣言 | `#FFFFFF` | 加粗白 |
| 宣言重音字 | `#E0762D` 或 `#59C2ED` | 1-2 个字换色 |
| 注解 | `#9CB3CC` | 浅灰蓝 |
| 数字 | `#E0762D` | accent 橙 |
| 单位 | `#9CB3CC` | 浅灰蓝 |
| 分隔线 `|` | `#3A4555` | 暗灰，1px 宽 30px 高 |

## 字号锚点

| 元素 | 字号 |
|---|---|
| 中央宣言 | 56-72pt |
| 注解 | 16pt |
| 数字 | 48pt |
| 单位 | 12pt |

## 数据墙排列规则

- **4 列等宽**，每列宽 240px，从 x=0 起
- 数字 textbox 居中对齐每列
- 数字之间用 1px × 30px 暗色竖线分隔（`#3A4555`）
- 数字和单位上下排，不要混成一行

## 何时用这个风格

- 想做"开场页"或"产品发布会的高潮 single slide"
- 主张本身够颠覆性，能用一句话立住（"重新定义 X"类）
- 数据指标已经收敛到 4 个核心数字
- 不适合：需要解释、需要对比、需要多个并列主张的场景

## 实现要点

- 宣言必须居中且占据视觉重心（y 中线±50），上下留白要大
- 重音字换色要克制：通常只换 1-3 个关键字，不要整句换色
- 数字字号不能小，48pt 是底线，更夸张可以做到 64pt
- 整页**不放任何 logo、tag、slogan**——纯粹宣言 + 数据，多一个元素都是干扰
