# 风格 A — 苹果式·克制留白

冷静、巨幅金句、大量黑色留白、单行价值点。**核心审美：删到不能再删**。

## 布局图（基准尺寸 960×540，PPT 16:9）

```
+--------------------------------------------------+
| 产品价值 · PRODUCT VALUE                          |  ← y=24, 顶部 tag, 14pt 极细
|                                                  |
|                                                  |
|  [巨幅金句行1, 48pt 加粗白, 关键词换色]            |  ← y=115
|  [巨幅金句行2, 48pt 加粗白, 关键词换色]            |  ← y=200
|                                                  |
|  —— (60×2pt 橙色短分隔线)                         |  ← y=320
|                                                  |
|  01        02        03        04                |  ← y=360, 28pt 橙
|  短语      短语      短语      短语                |  ← y=388, 20pt 白加粗
|  注解...   注解...   注解...   注解...             |  ← y=424, 12pt 浅灰
|                                                  |
|                       标准化·精细化·智能化         |  ← 右下 slogan 11pt, y=508
+--------------------------------------------------+
```

## 配色

| 元素 | 颜色 | 说明 |
|---|---|---|
| 背景 | `#0A0E1A` 或 `#1A1A1E` | 深蓝黑 / 近黑 |
| 金句主文字 | `#FFFFFF` | 纯白 |
| 金句关键词 | `#E0762D`（橙）或 `#59C2ED`（亮蓝） | 1-3 个字换色 |
| 顶部 tag | `#E0762D` 50% 不透明 | 低饱和 accent |
| 序号 01-04 | `#E0762D` | 橙 |
| 短语标题 | `#FFFFFF` | 白加粗 |
| 注解 | `#9CB3CC` | 浅灰蓝 |
| 分隔线 | `#E0762D` | 60px 宽 2px 高 |

## 字号锚点

| 元素 | 字号 |
|---|---|
| 顶部 tag | 14pt |
| 金句 | 44-48pt（如果是 2 行）/ 52-56pt（如果是 1 行） |
| 序号 | 28pt |
| 短语标题 | 20pt |
| 注解 | 12pt |
| 右下 slogan | 11pt |

## 留白要求

- **上下边距 ≥ 60pt，左右 ≥ 48pt**
- 4 列价值点之间至少留 24pt 间隙
- 价值点和金句之间至少留 80pt 垂直距离
- **不允许任何卡片底色、装饰条、图标圆圈**——只靠空白分隔元素

## 何时用这个风格

- 用户语气克制、企业气质高级感
- 内容是"产品理念""价值主张"类抽象表达
- 听众是审美敏感的设计/创意人群
- 不适合：数据密集型、对比型、流程型

## 实现要点

- 价值点用 4 列水平 textbox，**每列三个独立 textbox**（序号/短语/注解），不要拼成一个多行 textbox
- 分隔线用 `addGeometricShape("Rectangle")`，width=60, height=2
- 顶部 tag 字符间距加大（letter-spacing 2px）以呈现"印刷感"
- 关键词换色用富文本：金句 textbox 内部分 `<a:r>` 段落用不同 `<a:srgbClr>`
