# Design Plan Template — 设计方案输出模板

在用户没看过这份方案前，**禁止动手生成页面**。这份方案是用户审稿用的——文字层面的反复迭代比任何生成操作都便宜。

---

## 标准输出格式

```markdown
## 设计方案（请确认后我再生成）

### 风格 & 背景
- 风格：[苹果式·克制留白 / 华为·气势递进 / 特斯拉·数据墙 / 故事弧线]
- 背景：[复用模板第 N 页 / 纯深色 #0A0E1A]
- 输出格式：[HTML / PPTX-OfficeMCP / PPTX-Standalone / PNG]

### 金句
- 主标题：[一句金句,≤20 字,关键词位置用「」标出来提示后续换色]
- 副标题：[一句补充,≤20 字,可省略写"无"]

### 价值点（3-4 个,递进关系：[范围/时间/抽象]）
01 **[短语标题,4-8 字]**
   注解：[一行人话,15-30 字,含数字/动作/对比]
02 **[短语标题]**
   注解：[...]
03 **[短语标题]**
   注解：[...]
04 **[短语标题]**（可选）
   注解：[...]

### 视觉结构（粗略,文字描述即可）
- 顶部 [y≈40]：[tag / 主标题 / 留空]
- 中部 [y≈180]：[巨幅金句 / 中央宣言 / Before-After 对比块]
- 中下部 [y≈360-430]：[4 列价值点 / 数据墙 / 时间线]
- 底部 [y≈500]：[slogan / 留空 / 数据单位行]

### 配色
- 主背景：#XXXXXX
- 主文字：#XXXXXX
- 强调色（accent）：#XXXXXX
- 辅助色：#XXXXXX
```

## 写金句的几条铁律

1. **主标题用动词或对抗性结构**：「让方案穿透工序」✅ /「全链路智能闭环」❌
2. **避免空话**：禁用"赋能业务""提升效率""数字化转型"这类词
3. **关键词位置标出来**：用「」括号标注，方便后续生成时给这些字换 accent 色
4. **≤20 字**：超长就是失败，金句的本质是"一口气能念完"

## 写价值点的几条铁律

1. **短语标题 4-8 字**，用动词或对抗性名词：「穿透工序」✅ /「全链路闭环」❌
2. **注解必须有具体钩子**：数字（"延期 14 天，¥350K"）、动作（"方案触发二次交底"）、对比（"传统归档 vs 自动拦截"）
3. **15-30 字**：长了破坏留白，短了没信息
4. **递进关系不能省**，常见三种递进：
   - **范围递进**：单点 → 闭环 → 智能 → 数据
   - **时间递进**：当下 → 过程 → 未来 → 决策
   - **抽象递进**：工具 → 自动 → 智能 → 商业

## 用户确认的提问模板

输出方案后，**最后一句必须是这个，不要漏**：

```
以上是设计方案。可以开始生成了吗？或者哪里要改？
  □ 可以开始
  □ 改金句（主/副）
  □ 改某个价值点（请说编号）
  □ 改视觉结构
  □ 改配色 / 输出格式
```

用户明确说"可以"再进入实现步骤。
