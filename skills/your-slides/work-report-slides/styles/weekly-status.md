# 风格 A — 周报式（三栏 + 总状态灯）

固定三栏：上周完成 / 本周计划 / 风险阻塞。顶部总状态灯一眼看出本周整体状况。

## 配色

| 元素 | 颜色 | 说明 |
|---|---|---|
| 背景 | `#FFFFFF` 或 `#F8FAFC` | 白底（工作汇报默认白底，节省打印墨） |
| 主标题 | `#1F2937` | 深灰，不用纯黑（视觉柔和） |
| 副信息（汇报人/期） | `#6B7280` | 中灰 |
| 栏目标题 | `#1F2937` 加粗 | 深灰 |
| 分隔线 | `#E5E7EB` | 浅灰，1px |
| Bullet 点 ●（完成栏） | `#22C55E` | 绿 |
| Bullet 点 ●（计划栏） | `#3B82F6` | 蓝（中性，表"未来") |
| 状态灯 🟢 | `#22C55E` | 绿 |
| 状态灯 🟡 | `#F59E0B` | 黄 |
| 状态灯 🔴 | `#EF4444` | 红 |
| 状态灯 ⚪ | `#94A3B8` | 灰 |
| 责任人/时间标签 | `#6B7280` | 中灰，比正文小一号 |

## 字号锚点

| 元素 | 字号 |
|---|---|
| 主标题（W18 周报） | 28pt |
| 总状态灯文字 | 16pt |
| 副信息（汇报人/期） | 12pt |
| 栏目名（上周完成等） | 18pt |
| 正文 bullet | 12pt |
| 责任人/时间标签 | 10pt |
| 底部 KPI 行 | 14pt |

## 三栏宽度与位置

- 每栏宽 **288px**（含 16px 内边距），从 x=24 起
- 左栏 x=24，中栏 x=336，右栏 x=648
- 栏与栏之间留 24px 空隙
- 每栏内 bullet 间距 32px（足够呼吸但不浪费空间）

## 何时用这个风格

- 团队周会、双周会
- 听众是同事/直属上级（不是高管董事会，那个用 BLUF 向上汇报式）
- 内容量在 6-12 个 bullet 之间（少了空，多了挤）

## 实现要点

### 总状态灯放哪儿

放标题右侧，用"🟢 整体绿灯"或"🟡 局部黄灯（X 项有风险）"。**右侧不要再放 logo 或装饰**，状态灯是这页第一眼看到的东西，不能被任何元素抢风头。

### 风险栏的特殊处理

- 风险/阻塞栏的 bullet 用状态灯色（🟡 实心圆点 或 🔴 实心圆点），不用 ✓
- 每条风险后面**必须紧跟一行 "→ 需 XXX 决策/资源"**，否则就是干嚎不解决问题
- 如果本周确实没风险，写"本周无重大风险"一行就好，不要硬凑

### 底部 KPI 行

- 限 3-5 个核心指标，用 `·` 分隔
- 每个指标格式：`名 数值 ↑/↓变化 状态灯`
- 没有变化方向（↑↓）的指标说明你没追历史对比，建议补上

### 责任人/时间标签的位置

- 紧跟在 bullet 下一行，缩进 16px
- 用更浅的灰色（`#6B7280`）和更小字号（10pt），不抢风头
- 格式：`@姓名 W18-3`（W18-3 表示 W18 的周三，简洁好读）

## 不要做的事

- ❌ 把风险栏改用绿色 bullet：失去警示意义
- ❌ 三栏宽度不均：左大右小看着像设计师没对齐
- ❌ 顶部不放总状态灯，只放标题：老板第一眼抓不到重点
